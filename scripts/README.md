# Scripts operativos

Este directorio no contiene scripts de siembra, credenciales de prueba ni
utilidades que escriban directamente en el proyecto Firebase de producción.

Para validar reglas, autenticación y datos de ejemplo, use un proyecto Firebase
de desarrollo o los emuladores locales. El alta de usuarios y la asignación de
roles deben ejecutarse desde una aplicación de administración con Firebase Admin
SDK; nunca desde un script cliente ni desde el navegador.
